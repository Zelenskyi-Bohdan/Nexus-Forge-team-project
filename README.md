## :book: About the Project

**Wedding Photographer** is a responsive one-page website for a wedding photographer.

The project provides users with an easy way to:

* explore the photographer's portfolio;
* view customer feedback;
* learn more about photography services;
* find answers to frequently asked questions;
* contact the photographer and submit a booking request.

The website includes interactive sections, portfolio filtering, image pagination, feedback slider, FAQ accordion, contact form and a success modal.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Visit%20Website-success?style=flat)](https://zelenskyi-bohdan.github.io/Nexus-Forge-team-project/)

## :wrench: Technologies

* **HTML5** — semantic markup
* **CSS3** — responsive layout and styling
* **JavaScript** — interactivity and API integration
* **Vite** — project development and build tool
* **Swiper.js** — feedback slider
* **Modern Normalize** — CSS normalization
* **SVG** — icons and graphics
* **REST API** — receiving portfolio images, feedbacks and sending booking requests
* **Prettier** — code formatting

## :iphone: Responsive Design

The project follows a **Mobile First** approach.

Breakpoints:

*  Mobile — from `320px`
*  Tablet — from `768px`
*  Desktop — from `1440px`

The layout supports responsive images and Retina displays.

## :seedling: Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Navigate to the project directory

```bash
cd <project-folder>
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The project will be available at the local address provided by Vite.

### 5. Build the project

```bash
npm run build
```
